# Announcement

## English

daily-kural-js is a small library for the Thirukkural. It gives you the kural of the day, a random kural, search, and filters, in the browser and in Node. Drop `<daily-kural mode="daily">` on a page, or run `npx daily-kural-js daily`. All 1,330 kurals, three commentaries, no server. The code is MIT. The text comes from the Apache-2.0 dataset at github.com/tk120404/thirukkural.

https://www.npmjs.com/package/daily-kural-js
